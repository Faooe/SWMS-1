# Web Employee HR Recap Mobile Parity v62

- Menyamakan presentasi Rekap HR Employee web dengan mobile.
- Attendance Rate menjadi hero card dengan caption hadir/hari kerja.
- Metric attendance: Hadir, Tepat, Telat, Absen, Leave, Izin, Lembur, Kerja.
- Durasi ditampilkan dalam menit agar identik dengan mobile.
- Ketepatan, Total Telat, dan Pulang Awal ditampilkan sebagai chip sekunder.
- Completion Rate menjadi hero card dengan caption completed/total assignment.
- Status assignment ditampilkan sebagai chips: Approved, Progress, Review, Revisi, Rejected, Not Worked, Late Revision.
- Grafik Attendance menggunakan attended (Present + Late) sebagai bar biru.
- Grafik Assignment Selesai menggunakan bar hijau.
- Tidak mengubah API, perhitungan Work Calendar, subscription gate, atau export.
